SIUS vers ISIS WEB

Transforme les tirs enregistrés par les cibles électroniques SIUS en fichier « saisie hors ligne » à réimporter dans ISIS WEB.

📋 Mode d’emploi — de SIUS à ISIS WEB, série après série
  1. Avant la compétition : une fois séries et postes figés dans ISIS WEB, exporter la liste de départ (« SIUS - <compétition>.xlsx »), la charger dans SIUS et la garder (liste du jour).
  2. Après chaque série horaire : exporter le CSV des tirs depuis SIUS et le ranger dans le dossier de la compétition (Serie01.csv, Serie02.csv…). Ne pas supprimer les précédents.
  3. ISIS WEB : onglet Résultats → « Exporter saisie hors ligne ». Un seul export suffit tant que le plan de tir ne change pas (refaire l’export après tout ajout de tireur ou changement de poste).
  4. Cette page : zone 1 → déposer tous les CSV déjà récupérés (les doublons sont ignorés) ; zone 2 → la saisie hors ligne + la liste du jour. Cliquer « Reconstituer les matchs ».
  5. Contrôler : aucune alerte rouge, lire les points à vérifier (coup hors programme, série incomplète, rattachement « à vérifier »), coup d’œil aux podiums.
  6. Importer : « Générer le fichier pour ISIS WEB », puis dans ISIS WEB « Importer saisie hors ligne » → fichier …_rempli.xlsx → valider. Vérifier le badge vert.
⚠️ Alerte rouge = ne rien importer : les fichiers ne viennent pas de la même compétition, ou les dossards ont changé sans que la liste du jour soit chargée.
💡 Recharger tous les CSV à chaque fois : le fichier généré contient alors toutes les séries déjà tirées, rien n’est perdu à l’import.
🧪 Au premier usage, faire un import d’essai après la 1re série et vérifier dans ISIS WEB que les autres tireurs ne sont pas effacés.
